## Target format (byte contract — other tasks and docs mirror this exactly)

Per repo (`# <repo_url>` line), per branch (`## <branch>` line), each plan row renders:

```markdown
### planning/orbit-dmp/work_plan.md
| approval | priority | plan | title | state | remove |
|----------|----------|------|-------|-------|--------|
| ☐ | 1 | planning/orbit-dmp/work_plan.md | Task Plan: ORBIT DMP v0 | open | ☐ |

| details |
|---------|
| **Goal:** Build the DMP, table-first.<br>**Tasks:**<br>1 Skeleton & front matter<br>2 Master table 1 |
```

Rules:
1. `### <plan>` heading line (the `plan` cell text, e.g. `planning/<topic>/work_plan.md`).
2. Then `_LISTING_HEADER`, `_LISTING_SEPARATOR`, then the data row line **exactly as today** (`| ☐/☑ | <priority> | <plan> | <title> | <state> | ☐/☑ |`). The header/separator repeat for EVERY plan (each data row is its own table).
3. Then exactly one blank line.
4. THEN, only if `goal.strip()` is non-empty OR `task_titles` is non-empty, the details table: `| details |`, `|---------|`, content line. **Both empty → no details table at all** (user decision 2026-11-25 — no all-dash noise row).
5. Content line = `| ` + body + ` |` where body = `**Goal:** ` + (escaped goal or `—`) + `<br>` + `**Tasks:**` + for each task `<br>` + `<label> <title>` (stripped, escaped; when `task_titles` is empty nothing follows `**Tasks:**` beyond a single trailing `—`? — NO: keep it simple and symmetric: missing goal alone → `**Goal:** —`; empty tasks alone → `**Tasks:** —` rendered immediately after the goal part as `<br>**Tasks:** —`).
6. Joining: exactly ONE blank line between two consecutive plan blocks, exactly one blank line before the next `##`/`#` heading; no trailing blank line; file ends with a single `\n`. When a plan has no details table, the blank line after its data row serves as the separator before the next `###`/heading.
7. Empty `rows` → `""` (unchanged). Determinism (byte-stable fixed point) is mandatory — the reconciler compares `render_listing(new_rows) == current_md` to avoid push-less churn.
8. Backward compatibility of the PARSER (not renderer): live listings still contain old-format `| — | — | …` rows; the em dash fails `int()` → skipped (existing behavior, keep the test).
