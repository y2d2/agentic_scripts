# Task Plan: T3 — Phase 1 pipeline: repo scan, listing reconcile + push, reaper

**Purpose:** Turn the `roadmap_dev` pure core into a runnable Phase 1: on every run, reap orphaned `pending` plans, scan all `allowed_repos` (sandbox clone/fetch, all branches) for un-archived plans, reconcile the remote `plans.md` in the `ARP_prompts` clone, commit + push the listing when it changed, and persist state atomically — fully hermetic-testable against local fixture repos.

## Objective

Implement `RoadmapDevWorkflow.run()`'s Phase 1 (scan → reconcile → push → state persist) plus the run-start reaper (state flip + worktree cleanup), the git plumbing it needs (`Git.ls_tree`, `Git.mv`), and the prompts-repo clone handling — so that `run()` is end-to-end correct for the scan/reconcile surface before the drain (Task 4) exists.
